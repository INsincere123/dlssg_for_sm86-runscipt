# 使用说明

本说明适用于“启动脚本”文件夹里的启动器。普通用户从下面的步骤开始，无需阅读代码或手填AppID。

## 更新驱动后重新切换显卡名称

如果驱动更新已恢复真实显卡型号，但切换工具提示已有状态备份，在“启动脚本”文件夹打开 PowerShell，运行：

```powershell
.\切换显卡.bat -ResetState
```

也可简写为 `.\切换显卡.bat -r`。同意管理员权限后，脚本清除旧状态备份，以当前名称重新备份并切换；完成后手动重启电脑。当前仍是伪装名称时不能重置，应正常运行切换工具恢复。`-Status` 仅查看状态，不能与 `-ResetState` 同用。

## 保留 Engine.ini 的 DLSSG 通用启动器

双击 **通用启动器.bat** 使用独立通用入口。它保留游戏 Engine.ini，启用现有帧生成及 INT8 超分功能，没有画质档位和配置目录要求。原来的 **虚幻启动器.bat** 继续提供画质配置功能。

1. 完整解压文件夹，双击“启动脚本”里的 **通用启动器.bat**。首次游戏列表为空，之后保存到本机独立偏好。
2. 点击 **发现已安装游戏**，从 Steam、Epic、GOG 安装记录中选择游戏；也可 **手动添加游戏**，选择安装文件夹。不做全盘扫描；扫描可取消，跳过原因见 **扫描详情**。
3. 在候选列表中确认真实渲染程序。候选按目录结构和组件证据排序，请核对完整相对路径；平台启动程序可能与渲染程序不同，可在主界面分别调整。
4. Steam游戏使用 **Steam启动**；Epic、GOG和手动添加使用 **EXE启动**。后者仍需要满足游戏自身的登录、授权等条件；若游戏必须由平台启动，当前入口可能无法启动它。
5. 保存设置，可先点 **检查环境**，再点 **启动游戏** 并同意提权。界面交接后退出，请保留独立脚本窗口；退出游戏后等待恢复完成。

Steam程序、代理DLL及游戏路径可在主界面修改；渲染程序和启动程序填写安装目录内的相对路径。发现遗留部署后先点击 **恢复原状**，完成前不能修改原设置。若提示属于原启动器或其他游戏设置，回对应入口恢复，不能删除 `.state` 记录绕过。

找到游戏或通过检查不代表游戏支持帧生成；需要在游戏内确认 DLSS 帧生成是否可用。游戏搬盘后可重新选择目录；移动启动器后重新发现游戏即可，本机偏好不随分享包导出。

## 原画质启动器：第一次使用

1. 将收到的完整文件夹或压缩包解压到可写位置，保留所有文件的相对位置；不要只复制一个BAT，也不要在压缩包内运行。
2. 先按原来的方式启动游戏一次，进入游戏后正常退出，让游戏创建配置文件。
3. 双击“启动脚本”里的 **虚幻启动器.bat**。
4. 选好游戏和画质，点击 **启动游戏**，同意Windows管理员权限提示。
5. 启动器界面随后自动退出以释放内存，独立脚本窗口会继续负责监控和恢复。需要插帧时，在游戏内开启DLSS帧生成。
6. 正常退出游戏，等待独立脚本完成恢复并退出。不要强行关闭或结束该脚本。

目标环境是Windows 10/11 x64，组件主要面向RTX 20/30系列；当前验证环境为Windows 11。能打开启动器不代表所有游戏都能使用插帧或获得性能提升。

## 选择和添加游戏

内置黑神话：悟空预设会自动查找Steam登记的游戏库。游戏下拉框用于切换已添加的游戏。

| 按钮或选项 | 作用 |
|---|---|
| 选择当前游戏文件夹 | 为当前条目重新指定安装位置，例如游戏搬盘或自动查找失败；不会增加新游戏 |
| 添加其他游戏 → 添加 Steam 游戏 | 添加列表中没有的Steam游戏，AppID自动读取 |
| 添加其他游戏 → 添加EXE启动游戏 | 添加非Steam游戏，直接运行自己选择的EXE，无需Steam或AppID |
| 添加其他游戏 → 扫描已安装游戏（Steam / Epic / GOG） | 从平台登记中选择游戏，自动扫描程序和配置目录 |
| 添加其他游戏 → 扫描详情 | 查看扫描跳过原因 |
| 取消扫描 | 取消当前后台扫描，不保存未完成设置 |
| 重新查找 | 重新核对当前游戏；已存配置目录失效时尝试扫描配置位置 |
| 检查环境 | 预览部署并检查路径、文件和冲突，不启动游戏；仍会生成日志 |
| 恢复原状 | 清理上次遗留部署并恢复原配置，不启动游戏 |
| 查看日志 | 打开启动脚本日志文件夹 |

### 添加 Steam 游戏

选择安装文件夹后，启动器自动扫描渲染EXE和用户配置目录。也可通过“扫描已安装游戏”从平台登记中选择。

Steam可以保持运行。自动识别依靠Steam的安装登记；只复制游戏文件而没有对应清单时可能找不到AppID，先让Steam识别安装目录。

### 添加EXE启动游戏

选择安装文件夹后，启动器自动扫描渲染EXE和用户配置目录。扫描已安装游戏时，Epic/GOG自动使用EXE启动。

- Epic/GOG优先使用平台声明的启动EXE，其缺失时使用渲染EXE；手动添加使用选定的渲染EXE直接启动。
- 渲染程序通常位于 `项目名\Binaries\Win64`，名字可能以 `Shipping.exe` 结尾；有多个可信候选或证据不足时才提示选择。
- 两个EXE均应位于选定的安装文件夹内。用户配置文件夹通常位于用户目录，**不一定在安装文件夹内**，应包含 `Engine.ini` 或 `GameUserSettings.ini`。
- 先确认原版EXE能正常启动。游戏自身的平台登录或授权要求仍需满足；当前不提供自定义启动参数，也没有Epic等平台的专用启动适配。

程序有唯一可信匹配时自动采用。配置查找会检查游戏安装内及用户本地数据、文档/My Games下与项目名对应的 Saved/Config/Windows、WindowsNoEditor、WindowsClient。只有一个可信配置目录时直接填入；多个时选择，未找到时提示先原版启动一次或手选。不会创建游戏配置，也不会改变优化配置源。已有有效配置位置继续使用；有遗留部署时先“恢复原状”，扫描不能改变原记录的恢复位置。

## 怎么选画质

| 选项 | 建议 |
|---|---|
| 当前配置 | 使用该游戏原来选定的配置源；不代表不修改游戏配置，也不等于游戏原版画质 |
| 高性能均衡 | 第一档，适合较强的30系显卡，保留较多画面细节 |
| 主流均衡 | 第二档，新增游戏的默认选择，可先从这里尝试 |
| 性能优先 | 第三档，更积极减少远景、阴影等细节 |
| 入门流畅 | 第四档，画质取舍最大，适合性能较弱的设备尝试 |
| 05-自定义 | 使用自己维护的配置；按UE4/UE5选择对应文件，不代表比第四档更低画质 |

已有游戏保留“当前配置”；选择会按游戏保存。启动器不会按显卡自动选档，笔记本功耗和游戏差异也会影响合适的档位。切档前退出游戏并等恢复完成。

启动器首次会在后台识别UE4或UE5，成功后按游戏保存，以后直接使用已保存结果，不会每次重新扫描。游戏更新或搬盘后也保留结果；引擎版本需要变更时在高级设置手动校准。显示无法确定时，打开 **高级设置 → 引擎版本**，确认后选择UE4或UE5并点击“保存本机设置”。主版本未确定时不能使用四档候选或05-自定义配置；“当前配置”仍按原流程检查。

四档均为候选配置，可能降低画质或在某些游戏中不生效，不保证提升FPS。已有画面异常时先退回先前使用的配置。

“05-自定义”分别读取 `配置/虚幻通用分类/UE4/05-自定义/Engine.ini` 和 `配置/虚幻通用分类/UE5/05-自定义/Engine.ini`，可自行编辑对应文件。它与高级设置的“画质配置”是两条独立入口：前者固定使用这两个文件，后者选择任意INI并切回“当前配置”。启动器不会替你覆盖或合并自定义文件。

## 高级设置什么时候用

通常无需修改；遇到明确提示时再调整。

- **Steam**：仅Steam方式需要；未找到时选择本机的 `steam.exe`。
- **引擎版本**：自动识别失败或结果不正确时，手动校准UE4/UE5。
- **画质配置**：选择自己准备的明文INI并保存后，会切到“当前配置”。切换档位不会覆盖此前保存的自定义源。
- **代理DLL**：默认保留 `1 · version.dll`。其余编号依次为winmm、dbghelp、dinput8、dxgi、d3d12；一次只部署一个，不自动轮换。通常只在有针对性的兼容排查时修改。

高级设置的修改需点击“保存本机设置”；主界面的画质选择即时保存。发现未完成部署时，先恢复，再改画质、引擎或代理。

## 遇到问题

| 情况 | 处理方式 |
|---|---|
| 找不到游戏 | 使用“选择当前游戏文件夹”；未添加的游戏用“添加其他游戏” |
| 配置目录不存在 | 原版启动游戏一次；添加时选择实际用户配置文件夹 |
| 等待很久没有进入游戏 | 脚本最多等待120秒检测真实渲染进程，超时会尝试恢复；查看日志核对所选EXE和原版启动是否正常 |
| 游戏退出后脚本仍在 | 等待恢复；若报告冲突，保留窗口、日志和文件，记录错误后再处理 |
| 提示已有文件或其他代理冲突 | 不要直接覆盖或删除；先确认是否有其他Mod或旧部署 |
| 上次断电、崩溃或脚本被结束 | 关闭游戏，重新打开启动器，点击“恢复原状” |
| 添加EXE启动游戏后打不开 | 先退出部署并恢复，再检查原版EXE是否能单独运行、是否需要平台登录，以及启动/渲染EXE是否选对 |

不要通过删除 `.state`、备份或修改直接游戏的本机标识来绕过恢复。若恢复失败，保留现场，将最新脚本日志和错误信息交给配置提供者。

脚本日志位于“启动脚本”的 `logs` 文件夹；组件日志通常位于真实渲染EXE旁的 `dlssg_sm86\logs`。仅看到“已加载”不能证明插帧、INT8超分已实际执行，也不能用日志计数计算FPS收益。

插帧和INT8超分是两件事：前者补生成帧，后者改变部分超分计算。启用INT8开关不表示所有DLSS档位都加速；L/M预设是否实际使用INT8需看执行日志，同一次进程从L切到M或反向切换时可能需要重启游戏。

## 鸣潮、异环专用入口

这两款游戏也保留独立脚本，不必通过图形界面添加：

1. 用记事本打开同目录 `启动配置.ini`，核对对应游戏分组的游戏安装位置；换设备后不要继续使用旧盘符和用户路径。
2. 关闭对应游戏和官方启动器，双击 **启动鸣潮.bat** 或 **启动异环.bat**，同意管理员权限提示。
3. 在打开的官方启动器里进入游戏，正常退出后等脚本完成恢复。

鸣潮退出后默认可能额外等待10秒，供热更新重启使用；异环在首次游戏退出后清理。Steam和EXE启动方式不增加这段等待。游戏尚在运行时不会强行清理。

若需要手动恢复，在“启动脚本”文件夹的终端里执行对应命令；鸣潮、异环恢复前也需关闭官方启动器：

```bat
启动鸣潮.bat -RestoreDeployment
启动异环.bat -RestoreDeployment
```

`启动SteamUE5.bat` 是独立命令行入口，读取 `启动配置.ini`，与图形启动器的本机设置分开；普通用户可直接使用图形界面。

## 换电脑或发给朋友

可选Bandizip模式：运行 `打包给朋友.bat -b`，或给导出PS1传 `-b`。调用 `C:\Bandizip\bz.exe` 输出7z，使用本机7.32版默认LZMA2及最高等级 `-l:9`；压缩及完整性检查成功后只保留7z，失败保留导出目录。四种类型均可使用；不加 `-b` 仍用内置ZIP。打包脚本和Bandizip本身不包含在分享包内。参数依据[Bandizip官方说明](https://www.bandisoft.com/bandizip/help/parameter/)。

压缩包内只有一个顶层文件夹：类型1为“帧生成启动器”，类型2为“通用启动器”，类型3为“虚幻启动器”，类型4为“鸣潮异环帧生成解锁”；资源、说明和启动脚本均在其中，解压后进入该文件夹使用。

配置提供者双击本目录的 **打包给朋友.bat**，输入数字选择：**1 完整、2 通用启动器、3 虚幻启动器、4 鸣潮+异环**。完成后把仓库 `dist` 目录中新生成的ZIP发给朋友即可。文件名分别带Full、General、Unreal、WuWa-NTE，脚本会显示完整路径、大小与SHA256；压缩成功自动删除临时目录，不需要管理员权限或安装压缩软件。每次使用新名称，不覆盖旧包。

菜单最后的 **0 全部依次打包** 会按 **1 → 2 → 3 → 4** 分别生成四个包，沿用当前ZIP或Bandizip模式。已有输出冲突时整批不开始；执行中某类失败则停止后续打包，保留已完成的包和失败现场。

朋友完整解压ZIP，先阅读“先看这里.txt”。通用包打开 **启动脚本/通用启动器.bat**，虚幻包打开 **启动脚本/虚幻启动器.bat**，分别添加或查找自己的游戏。鸣潮+异环包先编辑 **启动脚本/启动配置.ini** 中的本机游戏目录，再运行对应专用BAT；配置模板不包含提供者的个人路径。完整包包含通用、虚幻和鸣潮+异环三类入口。

使用配置提供者新导出的完整便携包，到新设备重新解压，再添加或查找本机游戏。不要直接搬使用中的整个工作目录；旧设备有部署时先在旧设备完成恢复。

本机游戏路径与选择保存在当前用户的LocalAppData中，不包含在便携包内。移动启动器目录后可能需要重新添加直接游戏或重新确认设置；先在原位置恢复遗留部署，再移动。
