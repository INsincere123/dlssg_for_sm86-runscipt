# 第二参考筛选修订（2026-10-24）

本轮只更新UE4/UE5四档通用候选，不切换正式默认源。原始参考文件保留原字节，SHA256记录在来源快照。四份UET变体主要差异是VRR版增加关闭VSync与AllowTearing，低延迟版增加OneFrameThreadLag=0；它们不是显卡性能档位，未按档位套用。

## 实际变化

| 范围 | 修改 | 原因与边界 |
|---|---|---|
| 全八份 | 移除FramesForFullUpdate=10，沿用游戏 | 第二参考为2。较低间隔更及时、较高间隔省CPU，无法仅按GPU定档；需要时单独对比2/10。 |
| 全八份 | FullyLoadUsedTextures=0 | 不强制已用纹理最高mip一直驻留；不会取消资源自身的NeverStream，也不保证比游戏默认更省。 |
| 全八份 | UsePerTextureBias=1 | 在游戏已有MipBias时依预算按纹理分配；不主动写全局MipBias，不宣称单独节省显存。 |
| UE5第二至四档 | MaxPixelsPerEdge=1.5 / 2 / 3 | 第二参考为1.5，后两档为自定更粗几何候选；第一档保留游戏值。仅作用于Nanite，可能损失轮廓/植被细节。 |

现有Lumen、VSM、SSR、雾、距离及后处理梯度保留；不把第二参考的VSM采样4、雾网格16套到所有档位。新增覆盖也可能比具体游戏现值更昂贵；游戏未使用该渲染路径或定制引擎不支持CVar时不会获得对应效果。

## 未采用

- VRR、VSync、帧延迟、GTSyncType：按显示器、超分/插帧、CPU与延迟实测选取，不依30系型号硬套。
- 强制TAA/锐化、DLSS/FSR覆盖、全局禁用RT、关闭崩溃检测/超时及日志：不属于本轮性能分档。
- 强开线程、异步计算、D3D12策略、加载预算与GC参数：依赖游戏线程安全、CPU和引擎实现，无现场证据不覆盖。
- PSO缓存批次、编译速率与缓存模式：需要游戏实际缓存及引擎集成，不能保证消除首次编译卡顿，不写所谓通用万能值。
- HLODStrategy=0：可能改变游戏设计的远景纹理驻留；Nanite流送页数/池、硬件光栅阈值及VSM粗页剔除：可能改变资源预算或遗漏非Nanite阴影，暂不覆盖。
- 未确认的版本专用/拼写差异CVar不移植；不以参考文件包含该键作为游戏实际支持的证明。

## 依据与验收

[Epic纹理流送说明](https://dev.epicgames.com/documentation/en-us/unreal-engine/texture-streaming-configuration?application_version=4.27)说明了更新间隔、最高mip常驻与按纹理偏移的语义。

[Arm的Nanite实测说明](https://developer.arm.com/community/arm-community-blogs/b/mobile-graphics-and-gaming-blog/posts/mori-to-nanite-billions-of-triangles-on-mobile)用于确认像素边长增大时简化几何的方向。该实验是移动GPU和修改版UE5.5.2，不能用其帧率或百分比推断RTX 30系收益；本项目1.5/2/3仍需逐游戏验证。

只做静态INI、来源哈希、修改范围与备份校验。未启动游戏，未证明配置加载、跨版本兼容、画面可接受或FPS收益。优先对比跑图贴图响应、Nanite细枝/石头轮廓与运动稳定性，再测帧时间；不把加载日志计数作为FPS。
