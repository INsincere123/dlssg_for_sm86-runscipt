# 异环 UE5.6：本轮偏好优化

日期：2026-10-17。只修改异环配置源，未启动游戏；本配置是待验证的性能候选，不保证稳定达到插帧后120 FPS。

## 已确认的偏好

- 4K输出，优先减少卡顿、稳定接近插帧后120 FPS，并兼顾画质。
- 保留水面、玻璃、车漆等主要反射，先缩减较粗糙表面和不显眼的反射。
- 保留整体间接光，允许小细节简化，避免主动放慢光照响应或削弱时间稳定性。
- 保留人物近处阴影，小幅缩减远处阴影、模型和草木距离。
- 人群和车辆沿用上一轮候选值，泛光、景深及游戏内动态模糊选择不变。
- 温度问题本轮不处理；不修改鸣潮、启动脚本、DLL、驱动、分页文件或电源设置。

## 实际参数变化

| 组别 | 参数 | 优化前覆盖 | 本轮目标 | 代价与限制 |
| --- | --- | --- | --- | --- |
| 反射 | `r.Lumen.Reflections.MaxRoughnessToTraceClamp` | 未覆盖 | 0.3 | 缩减较粗糙表面的专用追踪；并非按水面/玻璃/车漆对象名称豁免 |
| 反射 | `r.Lumen.Reflections.MaxRoughnessToTraceForFoliage` | 未覆盖 | 0.2 | 参考5.6 High，避免直接设0；也可能影响采用次表面材质的角色表现 |
| 间接光 | `r.Lumen.ScreenProbeGather.RadianceCache.ProbeResolution` | 未覆盖 | 16 | 参考5.6 High；只降低相对于更高探针精度的空间细节，不改更新预算 |
| 远景 | `r.ViewDistanceScale` | 0.9 | 0.85 | 小幅缩减支持该机制的对象绘制距离 |
| 远景 | `r.StaticMeshLODDistanceScale` | 1.0 | 1.1 | 普通静态网格更早简化；Nanite/自定义路径可能不受影响 |
| 草木 | `foliage.LODDistanceScale` | 1.0 | 0.9 | 植被更早简化，不降低近处密度 |
| 草木 | `grass.CullDistanceScale` | 未覆盖 | 0.9 | 缩短支持UE草地机制的剔除距离，不代表密度90% |
| 阴影 | `r.Shadow.DistanceScale` | 未覆盖 | 0.85 | 缩减传统方向光阴影距离；不更改人物阴影分辨率，不能当作VSM通用优化 |

“未覆盖”只描述源文件：游戏实际默认值未知。若目标值等于现有值，则没有收益；若游戏已采用更低的成本设置，写入目标值也可能增加开销。表中涉及粗糙度、LOD与距离的数值是本机候选，不是官方对异环的推荐值。

Lumen参数不强制启用Lumen、不切换软硬件光追或反射方法。只有当前菜单选择实际使用对应Lumen路径时才有意义；本轮不猜测游戏GIMethod/ReflectionMethod枚举。保留反射采样分辨率、时间滤波、屏幕追踪和透明前层反射的游戏设置，保留间接光更新预算、表面缓存更新速度、屏幕探针间距、接触AO与背面光照。即使未主动改时间参数，降低空间精度仍可能增加噪点，需要画面对照。

纹理池与Nanite池不扩大，16倍各向异性过滤保持，流送更新间隔保持10；没有系统提交内存/显存数据时不把容量设置当作保证消除卡顿的办法。若跑图尖峰持续，可另用优化前副本单独撤掉FramesForFullUpdate覆盖作对照，不与本轮其他组同时混改。

## 文件与测试顺序

| 文件 | 当前含义 |
| --- | --- |
| `Engine.ini` | 现有异环BAT下次默认读取的本轮综合源文件 |
| `Engine.偏好优化.ini` | 本轮综合配置快照 |
| `Engine.正式组合.ini` | 同步为本轮综合配置，便于原有恢复命令继续使用 |
| `Engine.偏好优化前.ini` | 本轮修改前的完整字节副本，即上一轮流送＋城市正式版 |
| `Engine.仅Lumen优化.ini` | 优化前配置加三项Lumen覆盖；远景和阴影沿用优化前设置 |
| `Engine.仅远景阴影优化.ini` | 优化前配置加五项远景/草木/阴影调整；不启用本轮Lumen覆盖 |

此前的仅流送、仅城市、远景候选、缓存候选及原配置文件保留为历史对照，不自动混入本轮设置。它们与本轮正式版的基底不同，不应把切换后的变化全部归因于文件名标注的单组。

关闭游戏和启动器并等脚本清理结束后，通过原BAT传入 `-EngineConfigSource "候选明文文件完整路径"` 测试即可，无需覆盖默认源。测试顺序：优化前 → 仅Lumen → 仅远景阴影 → 综合。每组同路线重复三次，分开记录基础帧率和插帧后的显示帧率。保持分辨率、DLSS、插帧、天气与供电条件一致；温度不作为本轮调参项目，但比较时仍应尽量使用相近热机状态。

重点截图：潮湿路面/水面、车漆、玻璃、角色皮肤、近处阴影、室内霓虹染色、转镜头与跑图时的植被。出现明显反射变化、皮肤高光异常、光照噪点/闪烁或近景损失，回退相应组；没有超过重复测试波动的改善，不标记为有效优化。FrameView只有一轮时不能证明本配置提升了多少。
