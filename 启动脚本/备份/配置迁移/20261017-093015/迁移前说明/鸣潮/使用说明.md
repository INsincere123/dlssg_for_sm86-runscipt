# 使用当前配置启动鸣潮

先完全退出鸣潮和官方启动器，然后在 PowerShell 中运行：

```powershell
& 'D:\Games\dlssg_for_sm86\启动脚本\Run-WutheringWaves-DLSSG.ps1'
```

创建符号链接需要管理员权限，或系统已允许当前用户创建符号链接。如果提示权限不足，可在管理员 PowerShell 中运行同一命令。

脚本会在当前游戏安装的 `Client\Saved` 中寻找包含游戏设置节的 `GameUserSettings.ini`，不绑定 `WindowsNoEditor` 目录名。只有一个候选目录时自动使用；多个候选或没有候选时停止。目录改动后需根据当前游戏生成的文件核实，可手动指定：

```powershell
& 'D:\Games\dlssg_for_sm86\启动脚本\Run-WutheringWaves-DLSSG.ps1' -ConfigDirectory '实际配置目录的完整路径'
```

启动前，原 `Engine.ini` 会改名保留为同目录的 `Engine.ini.before-wuwaconfig-link`，包括原有只读属性。脚本将本目录的 `Engine.ini` 复制为游戏配置目录中的 `Engine.wuwaconfig-runtime.ini`，再让游戏的 `Engine.ini` 软链接指向该副本。游戏写入或清除注释只影响副本，仓库配置保持完整。修改仓库文件后，下次通过此脚本启动会重新复制。

游戏正常退出后，脚本移除临时链接和副本，恢复原文件。不要在游戏还运行时关闭脚本窗口，也不要同时运行多份脚本。只想检查路径和计划操作、不启动游戏时：

```powershell
& 'D:\Games\dlssg_for_sm86\启动脚本\Run-WutheringWaves-DLSSG.ps1' -DryRun -VerboseLog
```

若脚本被强行终止、系统重启或使用了 `-KeepLinks`，关闭游戏和启动器后恢复画面配置：

```powershell
& 'D:\Games\dlssg_for_sm86\启动脚本\Run-WutheringWaves-DLSSG.ps1' -RestoreEngineConfig
```

此恢复选项只处理画面配置。原有 DLL / DLSSG 链接由原启动流程管理。遇到同名文件被替换或异常链接时，脚本会拒绝覆盖；保留文件后检查日志中的备份路径。恢复成功后可重新正常启动。

项目根 README 的 FAQ 明确说不需要把 INI 设为只读，所以运行副本保持可写。README 还要求移除旧 `Client\Config\UserEngine.ini`，并去掉历史 `-EngineIni=Engine.ini` 启动参数；脚本遇到旧文件会停止，需先自行备份并移出。启动参数仍需检查所用快捷方式或启动器。

本配置只调整引擎参数。4K 输出、DLSS 超分档位、实际插帧倍率和显示 120 FPS 需要在游戏中确认；软链接存在或脚本检查通过不代表全部参数已被游戏接受。部署后检查实际画面、基础帧率、插帧后帧率和帧时间。
